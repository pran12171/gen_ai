WEEK 4 – TOKENIZER COMPARISON

Aim:
To compare BPE, WordPiece and SentencePiece tokenizers using English, Telugu and Hindi text.

What I Did:
1. Created a separate Python virtual environment.
2. Installed the required libraries.
3. Used pretrained tokenizers from Hugging Face.
4. Implemented BPE using GPT-2.
5. Implemented WordPiece using Multilingual BERT.
6. Implemented SentencePiece using XLM-R.
7. Compared tokens, token IDs and token counts for three languages.

Technologies Used:
Python, Hugging Face Transformers, SentencePiece and VS Code.

Files:
- tokenizer_comparison.py
- requirements.txt

Execution:
python tokenizer_comparison.py

Result:
Successfully implemented and compared three different tokenization approaches using English, Telugu and Hindi text.
