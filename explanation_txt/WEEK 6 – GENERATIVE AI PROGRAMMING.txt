WEEK 6 – GENERATIVE AI PROGRAMMING PRACTICAL

Aim:
To create a Golden Question Set and evaluate the answers generated by the Llama 3.2 model using Ollama.

What I Did:
1. Installed and configured Ollama.
2. Downloaded the Llama 3.2 model.
3. Created a Golden Question Set containing 30 questions.
4. Added expected answers, keywords and source links.
5. Developed a Python program to connect with Ollama.
6. Generated answers using Llama 3.2.
7. Compared generated answers with expected keywords.
8. Calculated keyword matching scores.
9. Classified results as PASS, REVIEW or ERROR.
10. Saved the evaluation results in a CSV file.
11. Created the first baseline evaluation release (v0.1).

Technologies Used:
Python, Ollama, Llama 3.2, Requests, JSON, CSV and VS Code.

Files:
- golden_set.json
- main.py
- requirements.txt
- baseline_results.csv

Execution:
python main.py

Result:
Successfully created a Golden Question Set and an LLM evaluation program to test the responses generated by Llama 3.2. The first baseline evaluation was labelled Release v0.1.
